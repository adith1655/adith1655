## Featured Projects

### 🔍 [UWSD — Unified Watch Surveillance Detection](https://github.com/adith1655/UWSD)
AI-powered face recognition and surveillance system built with TypeScript. Designed for real-time identity detection and monitoring workflows.

### 🤖 [Conversational AI Platform](https://github.com/adith1655/conversational-ai-platform)
Deep learning conversational AI powered by Gemini 2.5. Full-featured chat interface with context-aware responses.

### 🧠 [Gender Classification (CNN)](https://github.com/adith1655/gender-classification-python)
Convolutional Neural Network that classifies gender from facial images using TensorFlow and Keras. Demonstrates end-to-end ML pipeline: data prep → training → evaluation.

### 🔄 [LLM Extraction Pipeline](https://github.com/adith1655/llm-extraction-pipeline)
Production-style Python pipeline that ingests text from files and URLs, extracts structured insights via LLM, and outputs JSON, CSV, and summary reports.

### 🏃 [Multi-Object Tracking](https://github.com/adith1655/Multi-Object-Tracking)
YOLOv8 + ByteTrack pipeline for detecting and tracking people in sports videos with stable unique IDs across frames. Includes Gradio web UI, YouTube URL support, and GPU acceleration.

### 🏗️ [ConstructPay](https://github.com/adith1655/ConstructPay)
Full-stack platform replacing paper muster rolls and manual PF/ESI compliance for India's metro construction firms. Role-aware, mobile-first, built with TypeScript.
